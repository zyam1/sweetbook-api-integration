# SweetBook Image Upload (이미지 업로드) 가이드

## 개요

포토북에 사용할 이미지는 업로드 후 자동 처리되며,  
fileName을 기준으로 템플릿에 바인딩된다.

---

## 지원 이미지 포맷

JPEG

- .jpg, .jpeg

PNG

- .png (투명 배경 지원)

GIF

- .gif (첫 프레임만 사용)

BMP

- .bmp

WebP

- .webp (자동 변환 처리)

HEIC / HEIF

- .heic, .heif
- 자동으로 JPEG 변환

지원하지 않음:

- SVG (반드시 PNG/JPEG로 변환 후 업로드)

---

## 자동 처리

업로드 시 서버에서 자동 수행:

HEIC/HEIF 변환

- JPEG로 자동 변환

EXIF 회전 보정

- 이미지 방향 자동 수정

썸네일 생성

- 최대 800px 크기

주의:

- 원본 이미지는 그대로 유지됨

---

## 이미지 배치 모드

cover (채우기)

- 영역을 꽉 채움
- 일부 이미지 잘림 가능
- 배경/전면 이미지에 적합

contain (맞추기)

- 이미지 전체 유지
- 여백 발생 가능
- 로고/일러스트에 적합

주의:

- 배치 모드는 템플릿에서 정의됨
- API에서 설정 불가

---

## 파일 크기 제한

요청당 최대 크기

- 200MB

개별 파일 크기

- 제한 없음 (총합 기준)

---

## 해상도 가이드

권장:

- 300 DPI 이상

주의:

- 저해상도 → 인쇄 품질 저하
- SNS 이미지 / 캡처 이미지 사용 비추천
- 원본 이미지 사용 권장

---

## 썸네일 정보

응답 포함 데이터:

fileName

- 템플릿 바인딩 시 사용

originalUrl

- 원본 이미지 URL

thumbnailUrl

- 썸네일 URL

width / height

- 이미지 해상도

---

## 업로드 API

POST /books/{bookUid}/photos

특징:

- multipart/form-data 사용
- 여러 파일 동시 업로드 가능

---

## 핵심 규칙

1. 업로드 후 fileName 사용

- 템플릿 parameters에 반드시 fileName 전달

2. SVG 사용 금지

- 반드시 래스터 이미지로 변환

3. 이미지 품질 중요

- 저해상도 사용 금지

4. 업로드 → 바인딩 순서 유지

- 업로드 없이 바로 사용 불가

---

## 구현 주의사항

- HEIC 자동 변환되므로 별도 처리 불필요
- 썸네일은 미리보기용으로만 사용
- 업로드 실패 시 재시도 필요
- 여러 파일 업로드 시 용량 합계 체크 필요

---

## Claude Code 적용 목적

- 이미지 업로드 누락 방지
- fileName 기반 바인딩 강제
- 포맷 오류(SVG 등) 방지
- 품질 저하 이미지 사용 방지
