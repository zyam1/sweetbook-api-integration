# SweetBook API Error Guide

## 1. HTTP 상태 코드

SweetBook API는 다음 상태 코드를 사용한다.

| 코드 | 의미            | 설명                            |
| ---- | --------------- | ------------------------------- |
| 200  | 성공            | 요청 정상 처리                  |
| 201  | 생성 성공       | 리소스 생성됨                   |
| 400  | 잘못된 요청     | 파라미터 또는 필드 오류         |
| 401  | 인증 실패       | API Key 없음 또는 invalid       |
| 402  | 충전금 부족     | 결제 불가                       |
| 403  | 권한 없음       | 접근 권한 없음                  |
| 404  | 리소스 없음     | 존재하지 않음                   |
| 409  | 충돌            | 중복 요청 또는 idempotency 충돌 |
| 429  | Rate Limit 초과 | 요청 과다                       |
| 500  | 서버 오류       | 내부 오류                       |

---

## 2. 공통 에러 응답 구조

모든 에러는 동일한 구조를 가진다.

```json
{
  "success": false,
  "message": "Error message",
  "data": null
}
```
